# board-omega2S

Tarjeta base para el módulo **Omega2S**, diseñada para facilitar alimentación, expansión e integración del sistema dentro de un hardware propio.

## Propósito del proyecto
Este repositorio reúne una placa carrier para Omega2S junto con su sección de fuente de poder, permitiendo convertir el módulo en una plataforma más práctica para prototipos o productos embebidos.

## Qué incluye
- esquemático principal de la board
- esquemático de la fuente de poder
- PCB desarrollada en KiCad
- documentación asociada del regulador usado
